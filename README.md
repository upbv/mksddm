## Install

### Installer

[`install.sh`](install.sh) lists every theme release, asks for a number, downloads the build that matches your greeter (Qt5 or Qt6) and activates the theme:

```bash
git clone --depth 1 https://github.com/upbv/mksddm.git
cd mksddm
./install.sh
```

The script refuses to run when SDDM is not installed or is not the active display manager. It re-runs itself with `sudo`, installs into `/usr/share/sddm/themes/` and sets `Current` in `/etc/sddm.conf.d/theme.conf`. It needs `bash`, `curl` and either `jq` or `python3`; set `GITHUB_TOKEN` if the unauthenticated GitHub API rate limit is hit.

### Manual install

Download the theme archive from the [Releases page](https://github.com/upbv/mksddm/releases):

| Greeter | Asset |
| ------- | ----- |
| Qt6 (SDDM 0.21+) | `<theme>-qt6.tar.gz` |
| Qt5 (SDDM 0.20 and older) | `<theme>-qt5.tar.gz` |

```bash
tar -xzf <theme>-qt6.tar.gz -C /usr/share/sddm/themes/
```

To browse this index without downloading the full history:

```bash
git clone --depth 1 https://github.com/upbv/mksddm.git
```

Then pick the theme in **System Settings → Login Screen (SDDM)**, or write it manually:

```bash
sudo mkdir -p /etc/sddm.conf.d
printf '[Theme]\nCurrent=<theme-name>\n' | sudo tee /etc/sddm.conf.d/theme.conf
```

`<theme-name>` must match `Theme-Id` in the theme's `metadata.desktop`.

### Dependencies (Qt6)

| Package | Needed for |
| ------- | ---------- |
| `qt6-declarative` | Qt Quick / QML runtime |
| `qt6-5compat` | `Qt5Compat.GraphicalEffects` (ported themes) |
| `libplasma` | Plasma Components 3 (Federation, ittu, WinXPconcept) |
| `plasma5support` | battery data source (WinXPconcept, ittu) |
| `plasma-workspace` or `qqc2-breeze-style` | Breeze components (Sequoia and Breeze-derived themes) |
| `kirigami` | `Kirigami.Units` / `Kirigami.Icon` |
| `qt6-virtualkeyboard` *(optional)* | on-screen keyboard |

Package names are for Arch Linux; adjust them for your distribution.

## Changing the background

`theme.conf.user` overrides `theme.conf`. Edit it inside the theme directory, for example:

```ini
[General]
background=background-alt.jpg
type=image
```

Point it at a bundled image, or drop your own image into the theme directory and reference it here.
